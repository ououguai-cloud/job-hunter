在任意企业官网的投递页，一键自动填写姓名、手机、邮箱、学校、专业等个人信息。画像从职聘通网站同步，一处完善处处可用。

安装步骤（约 2 分钟）

  1. 点击上方「下载网申助手」，得到 extension.zip，解压到一个固定文件夹（例如 D:\jobhunter-extension）。
  2. 打开浏览器扩展管理页：Edge 访问 edge://extensions；Chrome 访问 chrome://extensions。
  3. 打开右上角「开发人员模式 / 开发者模式」开关。
  4. 点「加载已解压的扩展」→ 选择刚解压出来的 extension 文件夹（含 manifest.json 的那一层）。
  5. 扩展出现在列表里即安装成功。建议点工具栏「扩展」图标把它固定到工具栏方便调用。

使用流程

①
完善画像点扩展「📝 完善画像」直接填写，或在职聘通网站填写后同步
②
打开投递页打开任意企业官网的网申/投递页面
③
一键填写点扩展「⚡ 一键填写本页」自动填入个人信息

提示：插件可完全独立使用（自带画像编辑器），无需打开网站。验证码、简历上传、勾选同意条款等需手动处理；插件只填基本信息，不替你点「提交」。

为什么需要它？

原「一键投递」自动化引擎依赖 Node + puppeteer，公网静态站无法运行。网申助手改为浏览器扩展：登录、验证码、翻页你自己掌控，插件只负责把重复的个人信息填进去——更稳、更可控，几乎不受反爬限制影响。

🔒 隐私说明：画像数据仅保存在本扩展的本地存储（chrome.storage）中，不上传任何服务器。同步时也只是从职聘通网站页面的 localStorage 读取后存到扩展，全程在你的浏览器内完成。

常见问题

为什么我点了「从网站同步」却提示未找到画像？

请确保当前打开的是职聘通网站页面，并且在网站的「简历画像」里已经填写过信息（至少有姓名）。画像存在浏览器 localStorage，必须在该网站页面上同步。

为什么有的字段没自动填上？

插件用启发式规则识别字段（按标签文字、name、placeholder 匹配）。部分网站字段名很特殊时会无法识别，可在扩展里「查看/编辑」画像确认数据齐全，遇到无法识别的字段手动补填即可。

支持 Firefox 吗？

暂未适配 Firefox。当前支持 Edge / Chrome 及其他 Chromium 内核浏览器（如 360、QQ 浏览器的极速模式）。

安装后浏览器提示「不安全」？

这是 Chromium 对所有「开发者模式 / 未上架商店」扩展的通用提示，并非本扩展有问题。本扩展代码完全开源、权限仅 storage/activeTab/scripting，可自行审计。
