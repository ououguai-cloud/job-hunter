## 为什么是 JobHunter？

秋招投 100 份简历，90 份石沉大海——不是因为你不优秀，而是因为：简历信息不全被机器过滤、海投的岗位跟你不匹配、官网上千家公司根本筛不过来、每个官网都要重新填一遍表单。

JobHunter 把这条链路全部打通，**且你的简历永远不离开你的电脑**：

| 痛点 | JobHunter 的解法 |
|------|------------------|
| 简历信息不全，被 HR 系统直接过滤 | 📄 **简历分析**：PDF / 文本一键解析，自动提取 25 项画像字段，缺什么一目了然 |
| 不知道自己适合投什么方向 | 🧭 **动态方向检测**：17 个求职方向、100+ 关键词自动推断你的匹配赛道 |
| 海投 = 石沉大海 | 🎯 **智能岗位推荐**：多维评分 + **去同质化排序**（同公司最多 3-5 条、行业交错排列），Top 30 每一条都值得投 |
| 每个官网重新填一遍表单 | 🤖 **智能投递**：Puppeteer 机器人自动打开官网、识别表单、代填信息；验证码截图回传由你输入，**提交前整页截图人工确认**；不支持自动化的网站自动降级为**邮件投递**（自动生成求职信） |
| 简历写得空泛，一问就露怯 | ✍️ **简历体检**：23 项个人信息缺漏诊断 + 7 条正文规则检测（空泛词 / 无数据 / AI 腔…），每条附 **HR 可能追问 + 建议回答**，一键复制 |

> 全程本地运行：简历画像、投递记录、浏览器登录态全部保存在本机，**不上传任何服务器**。

## 🚀 快速开始（30 秒）

```bash
git clone https://github.com/ououguai-cloud/job-hunter.git
cd job-hunter
npm install
npm start
# 浏览器打开 http://localhost:8621
```

**前置要求**：Node.js ≥ 18，本机装有 Chrome 或 Edge（智能投递用，程序自动检测）。

> 开箱即用：自带开源模板画像（`resume/profile.example.json`）与完整岗位数据库，clone 后无需任何配置。

## 🌐 公开访问部署

要把链接分享给其他人，请部署**公共模式**（每位访客的画像与看板保存在其浏览器内，自动投递任务按会话隔离）：

最简单的方式：推送到 GitHub 后在 [Render](https://render.com/) 创建 **Blueprint** 并选择此仓库（项目内 `render.yaml` 会用 Docker 自动构建）。

也可在任意支持 Docker 的云主机运行：

```bash
docker build -t job-hunter .
docker run -d --name job-hunter -p 8621:8621 \
  -e PUBLIC_MODE=1 -e APPLY_HEADLESS=1 job-hunter
```

公共部署必须使用 HTTPS。不要把包含真实 `resume/profile.json` 的本地目录直接上传到服务器。

## ⚙️ 配置说明

### 简历画像（你的个人数据）

| 文件 | 作用 | 是否入库 |
|------|------|---------|
| `resume/profile.example.json` | 开源占位模板，所有人共享 | ✅ 随仓库分发 |
| `resume/profile.json` | **你自己的真实画像** | ❌ 已被 `.gitignore` 忽略，绝不会提交 |

使用方式：页面「简历分析 → 编辑简历画像」填写保存，或复制模板后直接编辑。画像同时驱动推荐打分、优化诊断与自动填表。

### 环境变量

| 变量 | 默认 | 说明 |
|------|------|------|
| `PORT` | `8621` | 服务端口 |
| `PUPPETEER_EXECUTABLE_PATH` | 自动检测 | Chrome/Edge 路径（检测失败时指定） |
| `APPLY_HEADLESS` | `0`（可见窗口） | 设为 `1` 后台无头运行 |
| `HOST` | `127.0.0.1` | 绑定地址，默认仅本机可访问 |
| `PUBLIC_MODE` | `0` | 设为 `1` 启用多人会话隔离 |

## 🤖 智能投递的工作原理

```
勾选岗位 → 后端启动浏览器（可见窗口）→ 打开官网招聘页
→ 启发式识别表单字段（姓名/手机/邮箱/学校/学历/简历附件…）自动填写
→ 遇到验证码：截图回传 → 你输入 → 机器人继续
→ 提交按钮：整页截图回传 → 你确认后才提交 → 自动登记看板
→ 不支持自动化的网站：自动降级邮件投递（生成求职信，一键发送）
```

**关键设计**：
- **验证码中继**：你只负责提供验证码和最终确认，筛选、填写、提交由引擎完成
- **持久登录**：独立浏览器 profile（`.profile/`），登录一次后续保持
- **可见窗口**（默认）：全程可监控，随时手动接管
- **邮件兜底**：自动投不了的，绝不硬塞——生成求职草稿由你过目后发出

## 🗄️ 岗位数据库

- **规模**：`db/jobs.json` 内 **38333 条岗位 × 10737 家公司**（1300+ 家 A 股上市公司程序化扩充）× 18 行业 × 34 省级行政区 323 市 × 20 类岗位 79 细分方向
- **投递赛道**：🎓 应届生 / ⏳ 往届生 / 📎 实习生 / 💼 社招，岗位卡片带彩色赛道徽章
- **公司分级**：🏅 大厂 / 中厂 / 小厂三档，可单独筛选
- **数据来源**：`data/companies.js` 公司元数据 → `node data/gen-jobs.js` 确定性生成（可复现、同公司不重复）；`node data/expand-companies.js` 从东方财富行情 API 自动扩充 A 股公司（支持断点续拉）
- **扩充方式**：跑扩充脚本 / 编辑公司库重新生成 / 前端「加入岗位库」粘贴 JSON / `node tools/crawler-template.js <URL>` 抓取导入

## ❓ 常见问题

- **Q：打开页面提示"离线示例模式"？** A：直接双击打开了 index.html，请通过 `npm start` 访问。
- **Q：自动投递会不会填错？** A：提交前有整页截图人工确认；无法识别的字段会暂停提示手动补齐。
- **Q：验证码能自动识别吗？** A：不破解验证码（合规优先），截图回传由你输入。
- **Q：如何保护隐私？** A：`resume/profile.json`、投递记录、`.profile/` 登录态全部被 `.gitignore` 忽略，不会随仓库提交。

## ⚠️ 合规提示
